# 개인정보와 데이터 관리

## 수집 범위

필수:

- 로그인 이메일 또는 OAuth 계정 식별자

선택:

- 반려동물 이름, 종, 품종, 생일, 성별·중성화, 체중, 프로필 사진
- 보호자가 작성한 관찰, 선택한 상태, 기록 날짜, 사진·영상
- 보호자가 옮긴 병원 안내와 병원 전달본 피드백

전화번호, 주소, 정밀 위치, 법적 신원과 주민등록정보는 수집하지 않습니다.

## 저장 위치

- 인증과 이메일: Supabase Auth
- 기존 표시명 호환 프로필: `tester_profiles` (새 전화번호 수집 없음)
- 반려동물과 예방접종: `pets`, `pet_vaccinations`
- 자동 시간 흐름과 관찰 기록: `episodes`, `health_reports`
- 첨부 메타데이터: `health_report_media`
- 보호자가 옮긴 병원 계획: `episode_plans`, `plan_tasks`
- 기존 장기 기록 호환 데이터: `episode_progress_logs` (읽기 전용)
- AI 전달본 본문·사용량·무료 공정사용 예약과 피드백:
  `ai_report_usage`, `ai_report_feedback`
- 과거 이용권 실험 호환 데이터: `ai_credit_grants`, `ai_credit_ledger`
- AI 전달본 공유 완료 신호와 과거 결제 실험 호환 데이터:
  `monetization_events` (무료 공개판은 `ai_summary_shared`와
  `factual_summary_shared`만 새로 기록)
- 과거 결제 원장: `billing_purchases`, `billing_events`
  (무료 공개판에서는 새 구매·결제 이벤트를 만들지 않음)
- 일반 기록 피드백: `health_report_feedback`
- 사진·영상 원본: Supabase 비공개 Storage 버킷

AI가 생성한 병원 전달 초안은 응답 유실이나 앱 재실행 뒤에도 사용자가 다시 열 수
있도록 계정·방문 흐름·선택한 원본 기록과 연결해 `ai_report_usage`에 저장합니다.
OpenAI에는 서버가 원본에서 만든 사실 문장과 번호만 보내고, 먼저 보여줄 번호의
순서만 선택하게 합니다. 요청은 `store: false`를 사용합니다. 같은 행에는 공정사용
예약, 성공·실패, 모델과 토큰 수도 함께 저장하며 사용자 본인과 서비스 역할만
접근합니다.

## 접근 통제

- Supabase Auth 토큰과 RLS가 모든 계정 소유 행을 제한합니다.
- 비공개 API는 서버에서 토큰과 데이터 소유권을 다시 확인합니다.
- 원문 기록과 AI 호출은 브라우저 `localStorage`에 저장하지 않습니다.
- 모바일 인증 세션은 OS 보안 저장소에 보관합니다.
- 파일 업로드 경로와 짧은 서명 URL은 서버가 발급합니다.
- Service role과 OpenAI 키는 서버 환경변수에만 둡니다.
- 무료 병원 전달본의 공정사용 예약과 사용 내역은 서버 원장에 기록하고 원자적으로
  처리합니다. 클라이언트 플래그나 참여코드로 권한을 만들지 않습니다.
- 무료 공개 앱은 RevenueCat을 초기화하거나 스토어 거래 식별자, 상품·환불 상태와
  구매 흐름 이벤트를 새로 수집하지 않습니다. 과거 실험 데이터가 남아 있다면
  서비스 역할로만 접근하고 계정 삭제 때 함께 제거합니다.

## 보관과 삭제

계정과 기록은 사용자가 삭제할 때까지 보관합니다. 사용자는 기록·반려동물을
개별 삭제하거나 계정 전체를 탈퇴할 수 있습니다. 탈퇴 시 비공개 파일과 Auth 사용자를
삭제하고, 연결된 기록과 남아 있을 수 있는 과거 DB 결제 실험 원장은 cascade로
삭제합니다. 무료 공개판은 RevenueCat 고객을 새로 만들지 않고 탈퇴 중 RevenueCat
API도 호출하지 않으므로, 배포 환경의 과거 비밀키나 외부 장애가 계정 삭제를 막지
않습니다. PetFlow 저장소 또는 Auth 삭제 실패를 성공으로 표시하거나 별도 공개 삭제
대기열에 남기지 않습니다.

AI 생성물은 진단이나 수의사 확인 정보로 표시하지 않습니다. 사용자 원문을 외부
분석 도구나 모델 학습에 기본 제공하지 않습니다.
